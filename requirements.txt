# yt-dlp with HTTP 403 unless it can impersonate a browser TLS fingerprint,
# which needs curl_cffi. Twitch and YouTube work without it; Kick does not.
#
# The upper bound is load-bearing. yt_dlp/networking/_curlcffi.py accepts only
# 0.5.10 and 0.10.x through 0.15.x, and refuses anything from 0.16 with
# "Only curl_cffi versions 0.5.10 and 0.10.x through 0.15.x are supported" —
# which presents as every impersonate target being listed as unavailable, and
# Kick still returning 403 even though curl_cffi is installed.
